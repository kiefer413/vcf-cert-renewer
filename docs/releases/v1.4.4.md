# v1.4.4 candidate

Classifies additional lego failures with fixed categories for DNS updates,
DNS propagation, ACME authorization, CSR validation and network/TLS errors.
Account, provider, rate limit and unknown categories remain available.
The signer keeps the numeric exit status and suppresses subprocess output.

This release preserves v1.4.3 provider selection, RFC2136/TSIG setup, renewal
and installation behavior. It cannot recover discarded historical output.
