# v1.4.5 candidate

Recognizes selected ACME problem codes from lego's error header. A generic
authorization phrase falls back to UNKNOWN_ACME_ERROR. Conflicting evidence
also falls back to unknown. A fixed operation is recorded only when a recognized
Let's Encrypt POST route is present in the matched header. DNS UPDATE and
propagation errors remain distinct. Output contains only exit status and fixed
diagnostic fields. No signing, DNS or installation behavior has changed.
