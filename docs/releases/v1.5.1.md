# VCF Certificate Renewer v1.5.1

Linux and Docker now check the public GitHub Release API after scheduled certificate
processing. Administrators can read cached update availability with `status --all`
or check immediately with `check-update --json`. Update events use the same JSON
logs and optional syslog destinations. Notifications persist across restarts.
No software is installed automatically, and GitHub outages do not affect
certificate health or replacement reconciliation.

- Default stable release channel, daily interval and optional prerelease checking.
- Pinned GitHub Actions updated to verified Node.js 24-compatible releases.
- Linux/systemd and Docker share the five-target scheduler and health state.
- [Update settings and Linux monitoring](https://github.com/kiefer413/vcf-cert-renewer/blob/v1.5.1/docs/automation-monitoring.md#software-update-notifications)
- [Docker deployment and upgrade](https://github.com/kiefer413/vcf-cert-renewer/blob/v1.5.1/CONTAINER_DEPLOYMENT.md)

**Production verification limitation:** Live issuance and certificate replacement
for Operations and Automation remain unverified. Those routes passed mocked
replacement checks and authenticated Fleet discovery and TLS checks.
