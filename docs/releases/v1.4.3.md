# v1.4.3 candidate

## Compatibility

Use `DNS_PROVIDER=dnsupdate` with lego 5.4.1. The provider still implements RFC2136 and uses the existing `DNSUPDATE_NAMESERVER`, `DNSUPDATE_TSIG_KEY`, `DNSUPDATE_TSIG_ALGORITHM`, and `DNSUPDATE_TSIG_SECRET` inputs. Legacy builds that advertise `rfc2136` can continue using that name. Provider selection is explicit. The image defaults to `dnsupdate`. Standalone installations default to `rfc2136` for legacy compatibility, so standalone lego v5 operators must set `dnsupdate` in their effective environment. Explicit settings override the default. Before ACME, the signer runs a bounded, credential-free provider help check. Use `lego dnshelp -c dnsupdate` to verify the installed binary before scheduling any live run.

The signer reports an exit code and fixed category for unsupported provider, missing account, rate limiting, or unclassified tool failures. No raw subprocess output is emitted. Other ACME and DNS errors may still require authoritative logs. No certificate installation workflow or DNS topology changes are included.

## Deployment and rollback

After approval, compare production to the approved v1.4.2 manifest and confirm the timer is disabled and inactive and the service has no active invocation. Prepare a reviewed source manifest and back up the exact affected source and protected service environment with original permissions and checksums, on the production host only. Stage and checksum the changed runtime files. Install them and set only the provider selection to `dnsupdate` for the existing lego v5 binary. Preserve the TSIG settings, ACME account state, and existing artifacts. Verify the installed manifest, version, imports, effective configuration and provider help without signing. Leave the timer disabled and inactive.

If verification fails, restore the verified source and environment snapshots together and verify v1.4.2, checksums and timer state. This restores the prior application and its known lego v5 incompatibility. A later controlled renewal requires separate approval.
