# v1.5.0 release candidate

Adds an explicitly configured five-role scheduler, persistent replacement
reconciliation, health state, structured events, logrotate and Linux watchdog
units, optional TCP/TLS syslog, and a shared Docker scheduler and healthcheck.
The lego 5.4.1 RFC2136 implementation continues to use `dnsupdate` and the ARI
workaround. B14 installation-only and existing VMware workflows are retained.

Upgrade by backing up the runtime, units and data. Configure role-to-FQDN policy,
review recovery acknowledgement and replace any legacy unrestricted timer command.
See [automatic renewal and monitoring](../automation-monitoring.md).

Operations and Automation use Fleet-managed TLS workflows. Verify deployment
SAN requirements and authorized Fleet access before enabling either. Review
runtime container validation and the publication checklist before tagging.

Production Linux has exercised SDDC Manager, vCenter and NSX replacement.
Operations and Automation use the implemented, mock-tested Fleet workflow.
Their live production checks covered trusted TLS and authenticated inventory.
Live issuance and replacement have not yet been exercised for those two roles.
