# Contributing

Thank you for helping improve VCF Certificate Renewer.

1. Open an issue before a large behavioral or component-scope change.
2. Keep credentials, customer data, generated certificates, and lab identifiers
   out of commits and fixtures.
3. Add or update tests for every behavior change.
4. Run the documented compile, unit, smoke, and public-marker checks.
5. Keep mutation routes fail-closed and preserve the four-component support
   boundary unless a separately reviewed release expands it.

Pull requests should explain the problem, safety impact, verification performed,
and any documentation or upgrade considerations. By participating, you agree to
follow the [Code of Conduct](CODE_OF_CONDUCT.md).
